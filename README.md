<p style="font-weight:bold; font-size:25px; color:#e4eaf2"> Sobre </p>

<p style="font-size:20px; color:#d3e1e3"> MyEngine é um projeto Web para trazer um mundo 3D ao navegador. </p>
<p style="font-size:20px; color:#d3e1e3"> O projeto contém as seguintes funcionalidades: </p>

<ul style="font-size:20px; color:#d3e1e3">
<li> Física e colisões. </li>
<li> Câmera em primeira pessoa. </li>
<li> Movimentação. </li>
<li> Classes para formas básicas (Cubo, esfera, plano, entre outros). </li>
<li> Classe para carregamento e gestão de textura. </li>
<li> Importação de modelos 3D. </li>
</ul>

<br>
<hr>
<br>

<p style="font-weight:bold; font-size:25px; color:#e4e1e3"> Tecnologias </p>

<p style="font-size:20px; color:#d3e1e3"> Todo o projeto foi escrito em javascript. </p>

<p style="font-size:20px; color:#d3e1e3"> Para a parte gráfica, foi usado a biblioteca <a href="https://threejs.org/">THREE.js</a>, que disponibiliza abstrações para o WebGL. </p>

<p style="font-size:20px; color:#d3e1e3"> Para a parte física, foi usado a biblioteca <a href="https://rapier.rs/">Rapier.js</a>, que disponibiliza sistemas de colisão, ray-casting, gravidade, forças, entre outras.</p>
